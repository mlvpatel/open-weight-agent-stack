assistance, and repository automation. GitHub's native Contributors graph is
left intact; this file records assistance that the graph cannot represent
without a real, account-linked commit identity.

## Repository automation

- **Dependabot** proposes pinned dependency updates.
- The **freshness watcher** records upstream observations and reports confirmed
  source drift.

These are repository automation, not AI co-authors.

## Attribution policy

- [GitHub's native Contributors graph](https://docs.github.com/en/repositories/viewing-activity-and-data-for-your-repository/viewing-a-projects-contributors)
  can show the top 100 commit authors and co-authors whose eligible commits are
  merged into the default branch. Merge commits and empty commits are not
  counted. A contribution links to a profile only when the commit uses an
  [email address associated with a GitHub account](https://docs.github.com/en/pull-requests/committing-changes-to-your-project/creating-and-editing-commits/creating-a-commit-with-multiple-authors).
- AI assistance is recorded here only when it materially affected repository
  work and has checkable evidence. Models and tools that are only discussed in
  the manual are not contributors.
- AI assistance is not a claim of legal authorship, copyright ownership,
  maintainership, or release authority. Those responsibilities remain with the
  human maintainer.
- The project does not create fake profiles, empty commits, or rewritten
  history to make a tool appear in GitHub's graph.
